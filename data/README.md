# Input data

The raw files are public but large, so they are not stored in this repository. Download them into this folder
with the file names below.

| File | Source |
|---|---|
| `01_WA_DOL_new_EV_registrations.csv` | Washington State Department of Licensing, Electric Vehicle Title and Registration Activity (data.wa.gov) |
| `02_AFDC_charging_stations_US_2023-12-31.csv` | U.S. Department of Energy, Alternative Fuels Data Center station list as of 31 Dec 2023 (afdc.energy.gov/data_download) |
| `03_supercharge_info_Tesla_sites.json` | Supercharge.info site list (supercharge.info) |
| `05_ACS_2022_5yr_B25032_housing_tenure_WA_tracts/` | U.S. Census Bureau, ACS 2018-2022 5-year, Table B25032, Washington tracts (data.census.gov) |
| `06_ACS_2022_5yr_B19013_median_income_WA_tracts/` | U.S. Census Bureau, ACS 2018-2022 5-year, Table B19013, Washington tracts (data.census.gov) |
| `07_MIT_county_presidential_returns_2000-2024.csv` | MIT Election Data and Science Lab, County Presidential Election Returns (doi:10.7910/DVN/VOQCHQ) |
| `08_access_dates_by_manufacturer.xlsx` | Compiled by the authors from carmakers' press releases (included in this repository) |
| `09_Census_gazetteer_2022_WA_tract_coordinates.txt` | U.S. Census Bureau, 2022 Gazetteer Files, census tracts |
